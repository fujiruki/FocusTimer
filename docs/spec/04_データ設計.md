# 04 データ設計

## UserDefaults

| キー | 内容 | 日付切り替えで破棄 |
|:--|:--|:--|
| `focus-timer-daily-v1` | `SavedPlan`（date, goals, session, startMinute, endMinute）のJSON | goals・sessionは破棄 |
| `focus-timer-reminder-interval` | 途中通知の間隔（分）。0=オフ、5/10/15。未設定時10 | 破棄しない |

## 主な型

- `DayGoal { id, title, steps: [WorkStep] }`
- `WorkStep { id, title, done }`
- `WorkSession { title, goalID?, stepID?, finishCondition, originalSeconds, extensionSeconds, elapsedBeforeRun, runStartedAt?, paused, laterNote }`

## Live Activity 属性（アプリとWidget Extensionで共有）

`FocusActivityAttributes`（固定属性なし）

`ContentState`:

| 項目 | 内容 |
|:--|:--|
| `headline` | 完成条件。未入力なら作業名 |
| `headlineIsCondition` | headline が完成条件なら true、作業名なら false（小見出しの切り替え用） |
| `goalTitle` | 今日のゴール名。なければ nil |
| `stepTitle` | 工程名。なければ nil |
| `timerStart` | 時間バーの起点（= 終了予定 − (当初＋延長)） |
| `timerEnd` | 終了予定時刻 |
| `pausedRemaining` | 中断中の残り秒。作業中は nil |
