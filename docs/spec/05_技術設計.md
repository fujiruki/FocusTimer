# 05 技術設計

## 構成

- SwiftUI、iOS 17以上、iPhoneのみ（縦向き）。
- プロジェクト生成: XcodeGen（`project.yml`）。`.xcodeproj` はコミットしない。
- ビルド: GitHub Actions（macos-latest）。シミュレーターでXCTestを実行後、未署名IPAを作る。
- 実機導入: Windows上の iloader（anisetteサーバー「SideStore (.zip)」）で無料Apple ID署名。
- 配布: main のビルド成功時に GitHub Release `latest` を作り直し、IPA を添付する（`https://github.com/fujiruki/FocusTimer/releases/latest/download/FocusTimer-unsigned.ipa`）。iPhone の SideStore から導入・7日ごとの再署名を行う。

## ターゲット

| ターゲット | 種類 | Bundle ID |
|:--|:--|:--|
| FocusTimer | iOSアプリ | `lab.akeru.focustimer` |
| FocusTimerWidgets | Widget Extension（Live Activity用） | `lab.akeru.focustimer.widgets` |
| FocusTimerTests | Unit Test | `lab.akeru.focustimer.tests` |

- アプリのInfo.plistに `NSSupportsLiveActivities = YES`。
- Live Activityの属性型は `Shared/` に置き、アプリとExtensionの両方でコンパイルする。
- 「気づくまで鳴らす」は AlarmKit（iOS 26以上）。Info.plist に `NSAlarmKitUsageDescription`。固定時刻のアラートのみでカウントダウン表示は使わない（Live Activityの追加は不要）。iOS 26未満では `#if canImport` と `#available` で無効化し、通知の鳴らし直しに切り替える。
- 音声ファイルは `FocusTimer/Sounds/`（WAV、通知・アラームとも30秒以内）。
- App Groupは使わない（Live Activityの内容はActivityKit経由で渡すため不要。無料署名で余計な権限を増やさない）。
- 残り時間・時間バーは `Text(timerInterval:countsDown:)` / `ProgressView(timerInterval:)` でシステムに描画させ、バックグラウンド更新やプッシュを使わない。

## テスト可能性のための分離

- 通知の予約計画（いつ・何を出すか）は純粋関数として分離し、XCTestで検証する。
- Live Activityの表示内容（ContentState）の組み立ても純粋関数として分離し、XCTestで検証する。
- `TimerStore` から通知センターとActivityKitへの呼び出しはプロトコル越しに行い、テストでは偽物に差し替える。

## 制約・未検証事項（実機で確認するまで「実装済み」扱いにしない）

- 無料Apple ID＋iloaderで、Widget Extension付きアプリを署名・導入できるか（拡張ごとにApp IDを消費。無料アカウントは7日間で10個まで）。
- Live Activityの表示条件（iOSバージョン、機種、設定でのLive Activity許可）。
- Apple Watchスマートスタックへの表示（watchOS 11以降、ペアリング設定）。
- 通知許可、集中モード下での通知の届き方。
- アプリが停止・終了された後のLive Activity残存と、起動時の引き継ぎ。
- 無料Apple ID署名でAlarmKitが使えるか、許可ダイアログが出るか。AlarmKitで独自音（長い版）が鳴るか（iOS 26ベータ期には独自音が無視される報告あり）。

### 代替案（Extension付きが導入できなかった場合）

1. Bと F8 だけの版（Extensionなし）を作り、まず実用する。影響: iPhoneを見た瞬間の想起（A）が得られない。
2. 有料Apple Developer Program（年額）で署名する。影響: 費用がかかり、主目的（無料・Windowsのみ）からは外れる。
