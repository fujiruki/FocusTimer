# 03 画面設計

## ホーム画面（1画面構成）

上から順に以下のカードを並べる。

1. 今日の24時間バー（活動範囲・現在時刻・活動終了まで）
2. 作業カード
   - 待機中: 作業名入力、時間選択、開始ボタン、**途中通知の間隔選択（オフ/5/10/15分）**
   - 作業中: **「今日のゴール → 今の工程」（小さく）**、作業名、完成条件入力、残り／超過、当初バー、延長バー、中断・再開／+5分／終了、後回しメモ
3. 音声入力カード
4. 今日のゴール → 工程カード

## Live Activity

### ロック画面

```
┌─────────────────────────────────────┐
│ 完成条件（太字・最大2行）        12:34 │
│ 今日のゴール → 工程（小・1行）          │
│ ▓▓▓▓▓▓▓▓░░░░░░░░ 時間バー               │
└─────────────────────────────────────┘
```

中断中は残り時間の代わりに「中断中 12:34」（静止）。

### Dynamic Island

- コンパクト左: 完成条件の短縮（1行、省略記号）
- コンパクト右: 残り時間
- 最小: 残り時間（またはタイマーアイコン）
- 展開: 中央に完成条件（2行）、右に残り時間、下にゴール

### Apple Watch スマートスタック

watchOS 11以降でiPhoneのLive Activityがスマートスタックに出る場合、完成条件と残り時間が読めること。可能なら小サイズ専用レイアウトを用意する。
