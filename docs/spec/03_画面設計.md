# 03 画面設計

## デザイン原則（全画面共通）

- 区切りの罫線は基本的に使わない。余白で情報をグループ化する。
- 「中は近く、グループ間は広く」: 見出しとその内容の間は小さく（2〜4pt）、グループ同士（例: 今日のゴール / 今回の完成条件 / 時間情報）の間は広く（20pt前後）取る。
- 見出しは小さく控えめ（caption・セカンダリ色）、内容を大きく。

## ホーム画面（1画面構成）

上から順に以下のカードを並べる。

1. 今日の24時間バー（活動範囲・現在時刻・活動終了まで）
2. 作業カード
   - 待機中: 作業名入力（マイク付き）、時間選択、どのゴールのため？（選択）、開始ボタン、「知らせ方」グループ（途中通知の間隔、終了時の鳴らし方、アラーム音＋試し聞き）
   - 作業中: 次のグループを広い余白で分けて並べる
     1. 今日のゴール（見出し＋ゴール名、工程名を小さく添える）
     2. 今回の完成条件（見出し＋作業名＋完成条件の入力・表示）
     3. 時間情報（残り／超過、当初バー、延長バー、経過）
     4. 操作（中断・再開／+5分／終了）
     5. あとでやること（メモ）
3. 今日のゴール → 工程カード（入力欄にマイク付き）
4. 音声入力カード（最下部に移動）
5. 最下部にビルド番号と最終更新日時（`ビルド #番号（コミット）　最終更新 M/d HH:mm`、端末のタイムゾーン）。ビルドから5分以内なら赤文字。実機のアプリが最新か確かめるため
6. ビルド番号の下に「Made by AKERU LAB」を小さく1行（控えめな色）。押すと https://akerulab.com/ を既定のブラウザで開く（AKERU-LAB/brand_credit.md）

## Live Activity

### ロック画面

```
┌─────────────────────────────────────┐
│ 今回の完成条件（小見出し）        12:34 │
│ 完成条件（太字・最大2行）               │
│                                         │
│ 今日のゴール  ゴール名（1行） 工程名（小）│
│                                         │
│ ▓▓▓▓▓▓▓▓░░░░░░░░                        │
└─────────────────────────────────────┘
```

- 完成条件が未入力のときは小見出しを「今の作業」にして作業名を出す。
- ゴールに紐づかない作業では「今日のゴール 未設定」と薄く出す。
- 中断中は残り時間の代わりに「中断中 12:34」（静止）、バーは出さない。
- 罫線は使わず、グループ間の余白で区切る。
- ロック画面のLive Activityは高さ約160ptが上限で、超えると切れる。上の配置で収まる高さに抑える。

### Dynamic Island

- コンパクト左: 完成条件の短縮（1行、省略記号）
- コンパクト右: 残り時間
- 最小: 残り時間（またはタイマーアイコン）
- 展開: 中央に完成条件（2行）、右に残り時間、下にゴール名

### Apple Watch スマートスタック

watchOS 11以降でiPhoneのLive Activityがスマートスタックに出る場合、完成条件・ゴール名（1行）・残り時間が読めること。可能なら小サイズ専用レイアウトを用意する。
