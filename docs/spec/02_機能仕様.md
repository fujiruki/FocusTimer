# 02 機能仕様

## 機能一覧

| ID | 機能 | 状態 |
|:--|:--|:--|
| F1 | 今日のゴールと工程の追加・選択・完了 | 実装済み |
| F2 | タイマー開始（計画なし／工程から）、中断・再開・+5分延長・終了 | 実装済み |
| F3 | 当初時間バー、延長バー、残り・超過表示 | 実装済み |
| F4 | 24時間バーと活動範囲（開始・終了は60分以上離す） | 実装済み |
| F5 | 完成条件（任意）、後回しメモ | 実装済み |
| F6 | 音声入力（各入力欄の横のマイク＋最下部の音声入力ブロック） | 実装済み（実機未確認） |
| F7 | 日付が変わったらゴールとセッションを破棄 | 実装済み |
| F8 | 作業画面に「今日のゴール → 今の工程」を表示 | 初期実用版で追加 |
| F9 | 途中リマインド通知（B） | 初期実用版で追加 |
| F10 | Live Activity（A） | 初期実用版で追加 |
| F11 | アラーム音の選択、終了時「1回鳴らす／気づくまで鳴らす」 | 追加 |

## F2 工程からの開始

- ゴールの下の工程の「開始」ボタンは、すぐにはタイマーを始めない。開始カードにその工程（作業名・ゴール）を設定し、開始カードまでアニメーションでスクロールし、開始カードを一時的に枠で強調する。
- 開始カードに「工程「◯◯」をこの設定で開始します」と表示する。時間・知らせ方を確認・変更してから、開始カードの開始ボタンで始める。

## F6 音声入力

- Apple の Speech フレームワークによる独自実装（iPhoneキーボードの音声入力とは別。キーボードの音声入力も全入力欄で使える）。
- 各入力欄（作業名・今日のゴール・工程・完成条件・あとでやること）の横にマイクボタンを置く。押すと録音を始め、認識結果をその欄に直接入れる（既存の文字があれば後ろに足す）。もう一度押すと止まる。
- 完成条件・あとでやることは、録音が止まった時点で保存する（完成条件は通知・Live Activityにも反映）。
- 別の欄のマイクを押すと、前の録音を止めて保存してから新しい欄で始める。
- 従来の音声入力ブロック（入力先を選んで反映）は画面の最下部に残す。

## F8 作業画面のゴール表示

- 作業中カードの先頭に「今日のゴール」グループ（小見出し＋ゴール名、工程名を添える）を表示する。
- ゴールに紐づかない作業（計画なし開始）の場合はグループごと表示しない。
- 工程に紐づかない場合はゴール名だけ表示する。
- 開始カードに「どのゴールのため？」の選択欄（なし／各ゴール）を置く。初期値は選択中のゴール、なければ未完了の工程がある（または工程のない）最初のゴール。「なし」も選べる。
- 開始カードから始めるとき、工程に紐づけるのは作業名がその工程名と一致する場合だけ。
- 作業中にゴールが未設定なら、作業カードからゴールを紐づけられる。紐づけると通知を予約し直し、Live Activityも更新する。

## F9 途中リマインド通知（B）

### 間隔設定

- 選択肢: オフ / 5分 / 10分 / 15分。初期値は10分。
- 設定は日をまたいで保持する（日付切り替えで消えない）。

### 予約する通知

作業開始時点（または再予約時点）を基準に、以下をローカル通知で予約する。

| 種類 | タイミング | タイトル | 本文 |
|:--|:--|:--|:--|
| 途中 | 基準からN分ごと | 完成条件（未入力なら作業名） | `残り{M}分` と、ゴールがあれば `／今日のゴール：{ゴール名}` |
| 残り5分 | 残り5分の時点 | `残り5分` | 完成条件（未入力なら作業名） |
| 終了 | 残り0の時点 | `設定時間になりました` | 完成条件（未入力なら作業名） |

- 旧仕様の「残り半分」通知は廃止し、途中通知に置き換える。
- 途中通知は、残り5分通知・終了通知の前後60秒以内に重なる場合は送らない。
- 残り時間が5分以下で開始・再予約した場合、残り5分通知は送らない（終了通知のみ）。
- 間隔オフの場合も、残り5分と終了の通知は送る。
- iOSの予約上限（64件）を超えないよう、途中通知は最大40件までとする。
- `{M}` はその通知が出る時点の残り時間（分、切り上げ）。
- 応答操作（ボタン）は付けない。
- 音: 途中・残り5分は短いチャイム（`focus_chime.wav` 約1.6秒）。終了はF11で選んだアラーム音。音量はiPhoneの着信音量に従い、消音モード・集中モード中は鳴らない（iOSの制約。無料署名では重要な通知や Time Sensitive の権限は使えない）。
- アプリを開いている（前面にある）ときも、バナーと音を出す。
- 超過中（残り0以下）に再予約した場合は何も予約しない。

### 再予約のタイミング

- 開始・再開・+5分延長・完成条件の変更・間隔設定の変更で、予約済みを全て消して予約し直す。
- 中断・終了で、予約済みを全て消す。
- 前日の保存データを破棄したときも消す。

## F11 アラーム音と終了時の鳴らし方

- アラーム音: チャイム／ベル／木琴／電子音／iPhone標準 から選ぶ。初期値はチャイム。試し聞きボタンで鳴らせる（iPhone標準は試し聞き不可）。
- 終了時: 「1回鳴らす」（初期値）／「気づくまで鳴らす」。
  - 1回鳴らす: 終了通知を選んだ音の短い版（約6秒）で1回鳴らす。
  - 気づくまで鳴らす（iOS 26以上でAlarmKitが許可されている場合）: 終了時刻にシステムのアラーム（AlarmKit）を鳴らす。「止める」を押すまで鳴り、消音モード・集中モードでも鳴る。このとき通常の終了通知は出さない。音は選んだ音の長い版（約28秒）。iPhone標準ならシステムのアラーム音。
  - 気づくまで鳴らす（AlarmKitが使えない場合）: 終了通知に加え、30秒おきに20回（最大10分）通知を鳴らし直す。音は長い版。アプリを開く（前面になる）か「アラームを止める」で残りを取り消す。消音モード・集中モードでは鳴らない。
- 「気づくまで鳴らす」を選んだときにAlarmKitの許可を求める。
- 中断・終了・延長などの再予約で、アラームも取り消し・予約し直す。
- 作業画面: 時間切れで「気づくまで鳴らす」のとき「アラームを止める」ボタンを出す。
- 設定は日をまたいで保持する。
- 予約通知の合計は最大62件（途中40＋残り5分＋終了＋鳴らし直し20）でiOSの上限64件以内。

## F10 Live Activity（A）

### 表示内容の優先順位

1. 今回の完成条件（未入力なら作業名）
2. 今日のゴール（ゴール名は必ず見せ、工程名は後ろに小さく添える。紐づいていなければ「未設定」と薄く出す）
3. 残り時間（システムのカウントダウン表示で自動更新）と時間バー（当初時間＋延長に対する進み具合）

- 完成条件と今日のゴールの両方を見せる理由: 「何のために今これをやっているか」を思い出しやすくするため。
- 長い文字列は省略してよいが、意味が分からなくなるほど削らない（完成条件は2行まで、ゴールは1行で末尾省略。ゴール名を工程名より先に置き、省略されるのは工程名側にする）。

### ライフサイクル

- 作業開始で開始する。
- 中断で「中断中」と止まった残り時間を表示する。再開でカウントダウンを再開する。
- +5分延長・完成条件の変更で表示を更新する。
- 終了で即座に消す。
- 残り0になったらカウントダウンは0で止まる（超過時間の常時更新はしない。後続検討）。終了通知はF9で出る。
- アプリ起動時、保存されたセッションがあれば既存のLive Activityを引き継いで内容を更新する（なければ開始し直す）。セッションがなければ残っているLive Activityを全て終了する。
- Live Activityが許可されていない・非対応の場合は何もしない（アプリ本体の動作は止めない）。

### 表示場所

- ロック画面（バナー）: 1〜3を全て表示。
- Dynamic Island（対応機種）: 幅に合わせて短縮。コンパクト=完成条件の短縮表示と残り時間、最小=残り時間、展開=1〜3（バーは省略可）。
- Apple Watch スマートスタック（watchOS 11以降で自動表示される想定）: 完成条件・今日のゴール（1行）・残り時間。**表示されるかは実機検証項目**であり、Watchアプリの代替と決めつけない。Watchの独立要件は継続検討。

### 操作ボタン

初期版ではLive Activity・通知に操作ボタンを付けない。

## 実機評価の観点（効果は断定しない）

1. iPhoneを見たとき、今の完成条件を読み取れるか。
2. 途中通知で作業へ戻れるか。
3. 連絡への返信を妨げないか。
4. 表示・通知がうるさすぎないか。
