# 02 機能仕様

## 機能一覧

| ID | 機能 | 状態 |
|:--|:--|:--|
| F1 | 今日のゴールと工程の追加・選択・完了 | 実装済み |
| F2 | タイマー開始（計画なし／工程から）、中断・再開・+5分延長・終了 | 実装済み |
| F3 | 当初時間バー、延長バー、残り・超過表示 | 実装済み |
| F4 | 24時間バーと活動範囲（開始・終了は60分以上離す） | 実装済み |
| F5 | 完成条件（任意）、後回しメモ | 実装済み |
| F6 | 音声入力（Speechで文字起こし、編集して反映） | 実装済み（実機未確認） |
| F7 | 日付が変わったらゴールとセッションを破棄 | 実装済み |
| F8 | 作業画面に「今日のゴール → 今の工程」を表示 | 初期実用版で追加 |
| F9 | 途中リマインド通知（B） | 初期実用版で追加 |
| F10 | Live Activity（A） | 初期実用版で追加 |

## F8 作業画面のゴール表示

- 作業中カードの先頭に、小さく「今日のゴール → 今の工程」を表示する。
- ゴールに紐づかない作業（計画なし開始）の場合は表示しない。
- 工程に紐づかない場合はゴール名だけ表示する。
- 計画なし開始でも、ゴールを選択した状態で開始した場合はそのゴールに紐づける（既存動作）。

## F9 途中リマインド通知（B）

### 間隔設定

- 選択肢: オフ / 5分 / 10分 / 15分。初期値は10分。
- 設定は日をまたいで保持する（日付切り替えで消えない）。

### 予約する通知

作業開始時点（または再予約時点）を基準に、以下をローカル通知で予約する。

| 種類 | タイミング | タイトル | 本文 |
|:--|:--|:--|:--|
| 途中 | 基準からN分ごと | 完成条件（未入力なら作業名） | `残り{M}分` と、ゴールがあれば `／今日のゴール：{ゴール名}` |
| 残り5分 | 残り5分の時点 | `残り5分` | 完成条件（未入力なら作業名） |
| 終了 | 残り0の時点 | `設定時間になりました` | 完成条件（未入力なら作業名） |

- 旧仕様の「残り半分」通知は廃止し、途中通知に置き換える。
- 途中通知は、残り5分通知・終了通知の前後60秒以内に重なる場合は送らない。
- 残り時間が5分以下で開始・再予約した場合、残り5分通知は送らない（終了通知のみ）。
- 間隔オフの場合も、残り5分と終了の通知は送る。
- iOSの予約上限（64件）を超えないよう、途中通知は最大40件までとする。
- `{M}` はその通知が出る時点の残り時間（分、切り上げ）。
- 応答操作（ボタン）は付けない。音は標準の通知音。
- 超過中（残り0以下）に再予約した場合は何も予約しない。

### 再予約のタイミング

- 開始・再開・+5分延長・完成条件の変更・間隔設定の変更で、予約済みを全て消して予約し直す。
- 中断・終了で、予約済みを全て消す。
- 前日の保存データを破棄したときも消す。

## F10 Live Activity（A）

### 表示内容の優先順位

1. 今回の完成条件（未入力なら作業名）
2. 残り時間（システムのカウントダウン表示で自動更新）
3. 今日のゴール（あれば。工程があれば「ゴール → 工程」）
4. 時間バー（当初時間＋延長に対する進み具合。判読性を損なう場所では省略）

### ライフサイクル

- 作業開始で開始する。
- 中断で「中断中」と止まった残り時間を表示する。再開でカウントダウンを再開する。
- +5分延長・完成条件の変更で表示を更新する。
- 終了で即座に消す。
- 残り0になったらカウントダウンは0で止まる（超過時間の常時更新はしない。後続検討）。終了通知はF9で出る。
- アプリ起動時、保存されたセッションがあれば既存のLive Activityを引き継いで内容を更新する（なければ開始し直す）。セッションがなければ残っているLive Activityを全て終了する。
- Live Activityが許可されていない・非対応の場合は何もしない（アプリ本体の動作は止めない）。

### 表示場所

- ロック画面（バナー）: 1〜4を全て表示。
- Dynamic Island（対応機種）: 幅に合わせて短縮。コンパクト=完成条件の短縮表示と残り時間、最小=残り時間、展開=1〜3。
- Apple Watch スマートスタック（watchOS 11以降で自動表示される想定）: 完成条件と残り時間。**表示されるかは実機検証項目**であり、Watchアプリの代替と決めつけない。Watchの独立要件は継続検討。

### 操作ボタン

初期版ではLive Activity・通知に操作ボタンを付けない。
