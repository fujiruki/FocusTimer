# 010 通知音が聞こえない問題への対処

- 状態: 採用
- 日付: 2026-10-14
- 関連コミット: `0c78618`
- 関連: spec/02_機能仕様.md（F9）

## 背景

晴樹さんの発言:

> 音が出てない気がする。　何回か使ってみたけど気づけなかった。　アラーム音の音量か音の継続時間か、そのほかか、、、

## 原因

- アプリを前面に出しているあいだは、通知がまったく出ない作りになっていた。iOSでは、専用の処理（`UNUserNotificationCenterDelegate`）を入れないと、前面のアプリの通知は表示も音も出ない。
- 標準の通知音は短く、作業中だと気づきにくい。

## 決定

- 前面にあるときも、バナーと音を出す（`ForegroundNotificationPresenter`）。
- 専用の音を作る。途中・残り5分は約1.6秒の2音のチャイム、終了は約6秒の音。
- 通知が鳴らない条件を仕様に明記する。

## 無料署名では回避できない制約

- 通知音の大きさは、iPhoneの「着信音と通知音」の音量に従う。アプリから上げることはできない。
- 消音モードではバイブだけになる。集中モード中は鳴らない。
- 集中モードを突破できる Time Sensitive 通知や重要な通知（Critical Alert）の権限は、無料署名では使えない。
- 消音モードでも鳴らしたい場合の対策として、「気づくまで鳴らす」（AlarmKit）を追加した（ADR-013）。

## 残るリスク

実機で音が聞こえるかは、まだ確認していない。
