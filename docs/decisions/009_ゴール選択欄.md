# 009 開始カードに「どのゴールのため？」を置く

- 状態: 採用
- 日付: 2026-10-14
- 関連コミット: `a0c783a`
- 関連: spec/02_機能仕様.md（F8）

## 背景

ロック画面の表示を詰めた（ADR-007）あとも、ロック画面にゴールが出なかった。晴樹さんは「アプリが更新されてないのかもしれない」と疑っていた。スクリーンショットの配置が新しい版のものだったので、更新はされていると判断した。

原因（AIの説明）:

> 開始カードで作業名を入力して始める場合、その前にゴールの丸ボタンを押して選んでおかないと、ゴールに紐づきません。しかもこの選択はアプリを開き直すと消えます。分かりにくい作りでした

## 決定

- 開始カードに「どのゴールのため？」の選択欄を置く。
  - 初期値は、選択中のゴール。なければ、未完了の工程がある（または工程のない）最初のゴール。
  - 「なし」も選べる。
- 作業中にゴールが未設定なら、あとから紐づけられるようにする。紐づけたら、通知とLive Activityを更新する。
- ロック画面に「未設定」と出し、紐づけ忘れに気づけるようにする（ADR-007）。
- 工程に紐づけるのは、作業名がその工程名と同じ場合だけにする。

## 理由

暗黙の操作（丸ボタン）に頼ると、紐づけ忘れが起きる。そのうえ、忘れたことに気づく手段もなかった。目に見える欄に初期値を入れておけば、何もしなくてもゴールに紐づき、変えたいときだけ選び直せばよい。
