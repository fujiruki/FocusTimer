# 014 工程の「開始」は即開始せず開始カードへ移る

- 状態: 採用
- 日付: 2026-10-14
- 関連コミット: `7f39cf6`
- 関連: spec/02_機能仕様.md（F2）

## 背景

晴樹さんの発言:

> 登録したゴールの下にいれた工程、それの右の開始ボタンを押したらタイマースタートしちゃうけど、そうじゃなくて上のセクションの工程に設定された状態になったうえでそのセクションのところまでスムーズにアニメーションスクロールして、この工程をこのアラーム設定で開始するんだ、とわかったうえで再度その開始ボタンを押したい

直前に、開始カードへ「知らせ方」（途中通知の間隔、鳴らし方、アラーム音）を加えていた。そのため、始める前に設定を確かめたい場面が増えていた。

## 決定

- 工程の「開始」を押したら、開始カードにその工程（作業名とゴール）を入れる。
- 開始カードまでアニメーションでスクロールし、カードの枠を一時的に強調する。
- 開始カードに「工程「◯◯」をこの設定で開始します」と表示する。
- 実際に始めるのは、開始カードの開始ボタンを押したとき。

## 理由

すぐに始めてしまうと、時間や知らせ方を選ぶ機会がない。開始カードに移って何が始まるかを見せ、確認してから押してもらえば、意図しない設定で始めてしまうことを防げる。
