# 011 ビルド番号と最終更新日時を表示する

- 状態: 採用
- 日付: 2026-10-14
- 関連コミット: `e0c9eae`, `a0c783a`
- 関連: spec/03_画面設計.md、`BuildInfo`

## 背景

晴樹さんの発言:

> どうやったら新しいアプリにちゃんと更新されたかって分かるんでしょうか

ADR-009のように「更新されていないのでは」と疑う場面が実際にあり、切り分けに時間がかかった。

## 決定

- 画面の最下部に `ビルド #番号（コミット）　最終更新 M/d HH:mm` を出す。番号はCIの実行番号、時刻はCIでビルドした時刻（端末のタイムゾーンで表示）。
- ビルドから5分以内なら赤字にする。
- 値はCIから `CURRENT_PROJECT_VERSION`、`FT_BUILD_COMMIT`、`FT_BUILD_TIME` として渡し、Info.plist に埋め込む。

## 理由

晴樹さんの発言:

> 現在のビルド番号のとなりに最終更新日時を表示すると良いな。それが表示している現在時刻の５分以内なら赤文字にする

番号だけでは、それが最新かどうかすぐには分からない。時刻があれば、いつのビルドか分かる。さらに赤字にすれば、入れたばかりの新しい版であることがひと目で分かる。

## 影響

- 「5分以内」はビルド時刻から数える。CIの完了からインストールまでに5分以上かかると、新しい版でも赤字にならない。
- 2026-10-15 に、SideStore で入れたアプリに「#17」と表示されることで、更新されたことを確認できた。
