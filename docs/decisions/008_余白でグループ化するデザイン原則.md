# 008 罫線を使わず余白でグループ化する

- 状態: 採用
- 日付: 2026-10-14
- 関連コミット: `0c78618`
- 関連: spec/03_画面設計.md「デザイン原則」

## 決定

- 区切りの罫線は基本的に使わない。余白で情報をまとまりに分ける。
- 見出しと中身の間は小さく（4pt）、まとまり同士の間は広く（22pt）とる。
- 作業中カードは、今日のゴール / 今回の完成条件 / 残り時間 / 操作 / あとでやること の5つのまとまりで構成する。
- この原則はアプリ全体に適用し、Live Activity にも罫線を使わない。

## 理由

晴樹さんの指示（貼り付け）:

> 区切りの罫線は基本的に使わず、余白で情報をグループ化してください

> 線で区切るより、『中は近く、グループ間は広く』の考え方を優先してください

線を引くと情報が細切れに見える。余白の近さと遠さで関係を示すほうが、ひと目で「どれが何の情報か」を読み取れる。
