# 004 サイドロードツールにApple IDを渡してよいか

- 状態: 採用
- 日付: 2026-10-14

## 背景

晴樹さんの質問:

> 認証情報はAppleにのみ送られるとあるけどほんとか？

## 調査

Impactor と iloader の公開ソースのうち、通信を担う主なファイルを読んだ。

- メールアドレスとパスワードの送り先は `gsa.apple.com` と `developerservices2.apple.com` だけ。SRP方式なので、パスワードは平文では送られない。
- 第三者の anisette サーバー（`ani.sidestore.app` など）へ送るのは、ランダムな端末IDと端末の登録データだけ。ただしIPアドレスは相手に見える。
- iloader で「認証情報を保存」をオンにすると、パスワードは Windows の資格情報マネージャーに保存される。

## 決定

ソースを見た限りでは「ほぼ本当」と判断し、今のApple IDのまま進める。AIは認証情報を扱わず、入力は晴樹さんが行う。

## 残るリスク

- すべてのコードを監査したわけではない。
- 配布されている実行ファイルが、読んだソースからビルドされたものかは確かめられない。
- ChatGPTは「可能なら開発専用のApple Accountを使う」ことを勧めている。問題が起きたら、専用アカウントへの切り替えを検討する。
