# 003 無料Apple IDで実機へ入れる（iloader／SideStore）。有料化は見送る

- 状態: 採用
- 日付: 2026-10-14〜15
- 関連: spec/05_技術設計.md

## 背景

未署名のIPAは、そのままではiPhoneに入らない。無料のApple IDで署名する必要がある。

途中で一度「数日待つしかない」と結論したが、晴樹さんがChatGPTの調査結果（iloader v2.3.7 で修正済み）を貼り付けてくれたため撤回した。

## 決定

- 当面は、PCを使わず7日ごとに再署名できる SideStore（Nightly）を使う。iloader はペアリングファイルの配置と、予備の導入手段として使う。
- 有料の Apple Developer Program（年99ドル）は見送る。

## 理由

晴樹さんの発言:

> 一旦 SideStore（無料 Apple ID）　やりたいな

> 有料化はもっと人に使わせたいものができそうになったときにする

有料化の利点として説明したもの: 署名が1年有効になる、CIで署名まで自動化できる、Time Sensitive 通知が使える、AlarmKit や Live Activity が動く見込みが高まる。どの方法でも「永続的に署名を保つ」ことはできない。

## SideStoreのペアリングでつまずいた点

- 「Pairing Required」が出た。iloader の「配置」で、SideStore にペアリングファイルを送って解決した。
- iOS 17 以降は Lockdown 方式では接続できない（`Broken pipe` や `early eof` が出る。SideStore #1532）。Remote Pairing を優先にする必要がある。AIが最初に「Lockdownを先に試して」と案内したのは誤りだった。
- Remote Pairing File を一度削除すると、再インポートが「ambiguous」で失敗する（SideStore #1611）。ペアリングファイルから Remote Pairing 用の4項目（public_key, private_key, identifier, alt_irk）だけを抜き出したファイルを作り、インポートした。
- ペアリングファイルは秘密鍵を含む。外部へ送らず、置き場所は晴樹さんのGoogle Driveのプロジェクトフォルダにした。読み込んだあとは削除する。
- 導入時の「App Contains Extensions」では、「Keep App Extensions (Register App ID for Each Extension)」を選ぶ。Remove を選ぶと Live Activity が使えなくなる。Use Main Profile では、拡張機能の Bundle ID と署名が合わないおそれがある。

## 影響・残るリスク

- 無料アカウントの制約: 有効なアプリは3つまで（SideStore自身を含む）、App IDは7日で10個まで、署名の有効期限は7日。FocusTimerは拡張機能付きなので、1回の導入でApp IDを2つ使う。
- 7日ごとの自動更新には LocalDevVPN の接続が必要。続けて動くかは未確認。
- 2026-10-15 にビルド #17 が SideStore 経由で入ったことを確認した。
