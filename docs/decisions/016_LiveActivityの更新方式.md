# 016 Live Activityはシステム描画に任せ、App Groupを使わない

- 状態: 採用
- 日付: 2026-10-14
- 関連: spec/05_技術設計.md

## 決定

- 残り時間とバーは `Text(timerInterval:countsDown:)` と `ProgressView(timerInterval:)` で表示し、描画をシステムに任せる。バックグラウンドでの更新やプッシュ通知は使わない。
- アプリから Live Activity を更新するのは、開始・中断・再開・延長・完成条件の変更のときだけ。
- App Group は使わない。

## 理由

- 提案書より:「プッシュサーバーは使わない。カウントダウン表示はOSが自動で進めるので、アプリが裏にいても止まらない」。サーバーを持たず、無料署名でも動く構成にするため。
- Live Activity に表示する内容は ActivityKit の ContentState で渡すので、アプリと拡張機能でデータを共有する App Group は要らない。無料署名で余計な権限を増やさないため。

## 代償

- 時間切れ後に「超過◯分」を出し続けることはできない（アプリが裏にいると更新できない）。そのため0で止める（決定記録6で了承済み）。

## テストしやすくするための分離

- 通知の予約計画と ContentState の組み立ては純粋関数にして、XCTest で確かめる。
- 通知センターと ActivityKit はプロトコル越しに呼び、テストでは偽物に差し替える。
