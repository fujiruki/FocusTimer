# 005 目標を忘れる問題に、Live Activity（A）と途中通知（B）の両方で対処する

- 状態: 採用
- 日付: 2026-10-14
- 関連コミット: `be16087`（仕様）、`0bb1c61`（テスト）、`0d543fb`（実装）
- 関連: spec/01_概要.md、spec/02_機能仕様.md（F8〜F10）

## 背景

試作版を実機に入れた直後の、晴樹さんの発言:

> インストールして使えた！　　でもこれさ、使ってるときに目標をを忘れる問題へのアプローチがないのでは？

要件書には、「5〜10分後には設定したこと自体を忘れる」「単なる終了通知では、途中の配分修正に間に合わない」とある。

## 検討した選択肢

| 案 | 内容 | 評価 |
|:--|:--|:--|
| C | 作業画面に今日のゴールを表示する | 簡単。ただし画面を見ないと効かない（→ F8 として採用） |
| B | 途中リマインド通知 | 没頭中でも時間をきっかけに思い出せる |
| A | Live Activity | iPhoneを見た瞬間に思い出せる。ただし無料署名で拡張機能付きアプリが入るか不確か |

AIの最初の提案は「C → B → A」で、Aは後回しだった。これをカンガルーに保存し（提案書）、晴樹さんがChatGPTと相談した。

## 決定（決定記録より）

> A：Live ActivityはB：途中リマインド通知と同じく重要であり、両方を初期実用版の必須機能とする。Bの効果を検証してからAの実装可否を判断する進め方にはしない

## 理由（決定記録より）

> 作業中にiPhoneを触ってしまうことがある。また、連絡には早く返信したい場合もある。iPhoneを見るその瞬間にも…思い出せるようにしたい

> 『作業中にiPhoneを見ないからAの優先度は低い』という先のChatGPT評価は、晴樹の実際の行動…を考慮していなかったため撤回する。AとBは代替ではなく補完関係である

- A: iPhoneを見たとき（LINEの確認など）に、ロック画面で思い出す。
- B: iPhoneを見ていない没頭中に、時間をきっかけに思い出す。
- スマホの使用は禁止しない。連絡を妨げず、元の作業へ戻りやすくすることが目的。

## 実装上の判断

- Live Activity の拡張機能だけ iOS 18 以上にした。Watch向けの `supplementalActivityFamilies` が iOS 18 からの API のため。アプリ本体は iOS 17 のまま。
- Apple Watch のスマートスタックは「表示されるか検証する対象」とし、Watchアプリの代わりになるとは決めつけない（決定記録7）。

## 影響・残るリスク

- 拡張機能付きアプリが無料署名で入らなかった場合の代替案（spec/05）: Bとゴール表示だけの版にする（Aの効果は失われる）か、有料署名にする（費用がかかり、主目的から外れる）。2026-10-15 に拡張機能付きで導入できた。
- 効果は断定しない。実機での評価の観点は spec/02 に書いた。
